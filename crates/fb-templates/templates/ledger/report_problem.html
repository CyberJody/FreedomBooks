Report a problem

FreedomBooks is an alpha. Keep your real books in your current software.

Problems are reported as issues on GitHub, the website where the FreedomBooks project lives. You need a free GitHub account.

GitHub issues are public. Anyone can read them. Never paste real financial data, customer names, passwords, keys or bank details.

  1. Open the GitHub issue page (it opens in your web browser). You can also copy the address: {{ issue_url }}
  2. Write the steps you took, one at a time, starting from Home.
  3. Say what you expected to happen.
  4. Say what actually happened. Copy any error message word for word.
  5. Copy your FreedomBooks version and operating system into the issue: 
    FreedomBooks version: {{ about.version }}
Operating system: {{ about.os }}
  6. Attach a screenshot only after covering names, amounts and account numbers.
